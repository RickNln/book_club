# Книга на ночь

Трекер книжного челленджа: отмечаем вечер чтения, ведём полку прочитанного, любуемся дашбордом.
Next.js 14 + Tailwind + Recharts, база — Postgres (Neon) через Drizzle, деплой — Vercel.
Регистрации нет: пользователей создаёт админ в разделе «Админ».

## Деплой на Vercel (≈10 минут)

1. Залейте папку в новый репозиторий на GitHub.
2. Vercel → **Add New → Project** → выберите репозиторий → **Deploy** (первый деплой упадёт без базы, это нормально).
3. В проекте: **Storage → Create Database → Neon (Postgres)** → Connect. Vercel сам добавит `DATABASE_URL`.
4. **Settings → Environment Variables** — добавьте:
   - `AUTH_SECRET` — длинная случайная строка (`openssl rand -base64 32`)
   - `APP_TZ` — `Europe/Moscow`
5. Создайте таблицы и первого админа — один раз, у себя на компьютере:
   ```bash
   npm install
   cp .env.example .env      # вставьте DATABASE_URL из Vercel и придумайте ADMIN_PASSWORD
   npm run db:push           # создаст таблицы
   npm run db:seed           # создаст группу, привычку «Чтение» и админа
   ```
6. Vercel → **Deployments → Redeploy**. Откройте сайт, войдите админом, в «Админ» создайте друга и отправьте ему логин и пароль.
7. На телефоне: Safari → «Поделиться» → «На экран Домой». Приложение откроется без браузерной обвязки.

## Локально

```bash
npm install && cp .env.example .env   # заполнить
npm run db:push && npm run db:seed
npm run dev
```

## Как устроено

- `src/db/schema.ts` — таблицы: `groups`, `users`, `habits`, `items` (книги), `entries` (отметки).
- Новая привычка = новая строка в `habits` со своими `fields`; серии и проценты считаются одинаково для любой.
- `src/lib/stats.ts` — серии, заморозки (1 в неделю по умолчанию), регулярность, ряд для волны.
- Вчерашний вечер можно отметить до 12:00 по `APP_TZ`.
- Сессия — подписанная cookie на 60 дней, пароли хэшируются bcrypt.

## Правила челленджа

Норма — 20 минут перед сном, засчитывается от 5 минут. Одна заморозка в неделю не рвёт серию.
Через 30 дней пересматриваем норму: 30 минут — если оба закрыли 25 из 30 дней.

## Обновления базы

Если в новой версии появились колонки, выполните SQL из `drizzle-manual/` в Neon (Vercel → Storage → база → Query, выключить Read-only) **до** пуша кода:

- `0001_avatars.sql` — аватарки участников.
- `0002_feed.sql` — мысли после чтения, лента и комментарии.
- `0003_freeze_sessions_rating.sql` — оценка книги, «дочитал(а)» в ленте, пометка «изменено».
